Hola, soy KPVDEV!!
Estoy empezando GameDeV y WebDev por lo que este seria
mi primer proyecto publico y funcional.
El juego esta basado en "Slime Rancher" y "MOKEPON",
el cual es un proyecto publico.

## Como jugar

Abre `mokepon.html` en un navegador. Elige un slime, recorre el mapa con WASD,
las flechas o los botones de pantalla y choca con otro slime para comenzar el
combate. Elige cinco ataques para ver el resultado.

El juego se ejecuta localmente en el navegador; no necesita un servidor aparte.
